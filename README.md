# Задание №4

## Доменные зоны

### 1. Пользователи

Зона отвечает за регистрацию агентств, учётные записи пользователей, авторизацию, восстановление доступа и управление правами сотрудников.

#### Глоссарий

| Термин | Определение |
|---|---|
| Агентство | Организация, использующая uTravel для подготовки путешествий для своих клиентов. |
| Учетная запись | Данные пользователя, необходимые для его идентификации и доступа к сервису. |
| Роль | Набор полномочий пользователя в сервисе. |
| Менеджер агентства (относится к Роли) | Сотрудник, который создаёт и редактирует маршруты и готовит предложения клиентам. |
| Руководитель агентства (относится к Роли) | Пользователь, который управляет сотрудниками и подпиской агентства, а также может выполнять функции менеджера. |

### 2. Планирование маршрутов

Зона отвечает за создание программы путешествия на основе параметров поездки, распределение выбранных мест и услуг по дням, редактирование и сохранение маршрута, расчёт расходов и подготовку предложения клиенту.

#### Глоссарий

| Термин | Определение |
|---|---|
| Параметры поездки | Пункт отправления, направление, даты, бюджет, количество путешественников и их предпочтения. |
| Маршрут | План путешествия с распределёнными по дням местами, услугами и перемещениями. |
| Элемент маршрута | Включённое в маршрут посещение места, проживание, перемещение или другая услуга. |
| Бюджет поездки | Установленная предельная сумма расходов на поездку для всех путешественников. |
| Расчётная стоимость поездки | Сумма известных предполагаемых расходов по элементам маршрута. Если часть цен неизвестна, расчёт считается неполным. |
| Предложение для клиента | Подготовленная агентством программа поездки с предполагаемыми расходами и ссылками на услуги. |

### 3. Подбор мест и услуг

Зона отвечает за поиск подходящих вариантов проживания, питания, развлечений и транспорта с учётом параметров поездки. Предоставляет описания, предполагаемые цены и ссылки для включения выбранных вариантов в маршрут.

#### Глоссарий

| Термин | Определение |
|---|---|
| Место | Географический объект, который можно включить в путешествие: отель, ресторан, достопримечательность и другие объекты. |
| Туристическая услуга | Проживание, питание, перевозка, экскурсия или другая услуга для путешественников. |
| Вариант услуги | Конкретное предложение, найденное с учётом параметров поездки. |
| Предполагаемая стоимость услуги | Оценка расходов на вариант услуги для указанных дат, количества путешественников и других условий. |
| Источник данных | Внешний сервис или официальный ресурс, из которого получены сведения о месте или услуге. |
| Ссылка на услугу | Адрес внешней страницы для просмотра сведений об услуге или перехода к бронированию. |

### 4. Подписка

Зона отвечает за оформление и продление подписки, учёт ее срока действия и статуса. Предоставляет сведения о праве агентства пользоваться платными возможностями uTravel.

#### Глоссарий

| Термин | Определение |
|---|---|
| Подписка агентства | Право агентства использовать платные возможности сервиса в течение оплаченного периода. |
| Период подписки | Промежуток времени, на который агентству предоставлен платный доступ. |
| Стоимость подписки | Сумма, которую агентство оплачивает за определённый период использования сервиса. |
| Статус подписки | Состояние подписки, позволяющее определить, действует ли она в текущий момент. |
| Продление подписки | Предоставление следующего оплаченного периода использования сервиса. |

### 5. Партнёрские комиссии

Зона отвечает за учёт бронирований, связанных с партнёрскими ссылками uTravel, получение подтверждений от партнёров и учёт начисленных вознаграждений.

#### Глоссарий

| Термин | Определение |
|---|---|
| Партнёр | Внешний сервис или организация, выплачивающая uTravel вознаграждение за бронирования по условиям сотрудничества. |
| Партнёрская ссылка | Ссылка, позволяющая партнёру связать переход и последующее бронирование с uTravel. |
| Партнёрское бронирование | Бронирование во внешнем сервисе, связанное с переходом по партнёрской ссылке uTravel. |
| Партнёрская комиссия | Вознаграждение uTravel за подтверждённое партнёрское бронирование. |


## GIVEN + WHEN = THEN

### Критический путь

В качестве критического пути выберем: Планирование маршрута на основе введенных параметров.

#### Сценарий 1 (Сценарий успеха)

**Дано:** Пользователь на странице генерации маршрута 
**И:** пользователь авторизован 
**И:** пользователь имеет подписку для генерации маршрута
**И:** пользователь ввел корректные параметры поездки.
**Когда:** Пользователь запускает генерацию маршрута.
**Тогда:** Система показывает маршрут по дням, подобранные места и услуги с предполагаемой стоимостью и расчётную стоимость поездки
**И:** пользователь может перейти к редактированию маршрута.

#### Сценарий 2 (Сценарий отказа)

**Дано:** Пользователь авторизован и находится на странице генерации маршрута.
**И:** пользователь указал дату окончания поездки раньше даты начала.
**И:** остальные обязательные параметры поездки заполнены корректно.
**Когда:** Пользователь нажимает «Сформировать маршрут».
**Тогда:** Система не запускает генерацию.
**И:** показывает рядом с полем даты окончания сообщение: «Дата окончания поездки не может быть раньше даты начала».
**И:** сохраняет введённые параметры поездки.
