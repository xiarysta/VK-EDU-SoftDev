## Стек технологий MVP

**React + TypeScript** — веб-интерфейс и редактор маршрутов. React упрощает создание интерактивных компонентов, TypeScript помогает обнаруживать ошибки в работе с данными.

**Python + Django REST Framework** — серверная логика и API. Готовые средства авторизации, работы с базой данных и администрирования ускоряют разработку MVP.

**PostgreSQL** — хранение пользователей, агентств, маршрутов и подписок. Подходит для связанных данных и обеспечивает согласованность изменений через транзакции.

**Celery + Redis** — фоновая генерация маршрутов, подготовка PDF и отправка писем. Длительные операции выполняются отдельно от обработки обычных запросов.

**S3-совместимое хранилище** — хранение PDF-предложений и логотипов агентств отдельно от базы данных.

**Gunicorn + Nginx** — запуск серверного приложения и обработка веб-запросов. Gunicorn запускает Django-приложение, Nginx принимает HTTPS-запросы, отдаёт статические файлы и перенаправляет запросы к API.

**[Plantrip API](https://plantrip.io/developers)** — специализированный ИИ-сервис для генерации маршрутов по дням и оценки расходов. Готовые инструменты планирования сокращают объём собственной реализации.
