## Стек технологий MVP

**React + TypeScript** — веб-интерфейс с формой параметров поездки и редактором маршрутов. React позволяет обновлять маршрут и бюджет без перезагрузки страницы, TypeScript помогает проверять структуру данных.

**Python + Django + Django REST Framework** — серверная логика и API для авторизации, работы с маршрутами и пересчёта стоимости. Django предоставляет ORM и административную панель для ручного создания учётных записей на пилоте, а DRF упрощает обмен данными с React-интерфейсом.

**PostgreSQL** — хранение агентств, пользователей, маршрутов и состояния генерации. Связи между таблицами и транзакции обеспечивают целостность данных при редактировании маршрутов.

**Gunicorn + Nginx** — запуск и публикация приложения. Gunicorn запускает Django, Nginx принимает HTTPS-запросы, отдаёт React-интерфейс и направляет запросы к API.

**[Plantrip API](https://plantrip.io/developers)** — внешний сервис генерации маршрутов по дням и оценки расходов. Асинхронная генерация с проверкой статуса через Django API позволяет обойтись без собственной очереди фоновых задач в MVP.
